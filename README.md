# 삼척 어드벤쳐
![Preview-1](https://github.com/user-attachments/assets/cb30f31d-c022-41f8-9972-7dbec2a95596)
> 고등학교 3학년 2학기 팀 프로젝트 수행평가 과제입니다.
> 퍼즐 및 전투 시스템이 있는 플랫포머 게임입니다.

# 개발 참여 인원
| **역할** | **이름** | **설명** |
|------|-------|------|
|클라이언트 개발|이인환|- 기획에 맞추어 게임 개발 및, 맵 디자인이 편할 수 있도록 툴 세팅|
|기획, 맵 디자인|송현오, 송우민|- 기획 및 아이디어 제공, 레벨 디자인 |
|발표 및 PPT 제작|김경수|- 수행평가 발표 및 PPT 제작|
